CASE STUDY IMAGES
=================

Drop the exported Figma PNGs into THIS folder using the exact filenames below.
The case study page (case.html?id=thinkproject) looks for these names.
Until a file exists, the page shows a tidy "Image coming soon" placeholder, so
nothing breaks if some are missing.

How to export in Figma:
  1. Select a frame on the canvas.
  2. In the right panel, scroll to "Export", click +, choose PNG (set 2x for crispness).
  3. Click "Export [frame name]" and save into this folder with the name above.
  (Tip: you can multi-select all frames and export them in one go, then rename.)
